# Soldier: A Day
### Multiplayer Military Survival RPG (Web 3D)

> **"18일 동안 군 생활을 생존하라."**

---

# 1. 프로젝트 개요

## 게임명

**Soldier: A Day**

## 장르

- Multiplayer Survival RPG
- Military Life Simulation
- Co-op
- Quest RPG

## 플랫폼

- Web Browser
- 3D Multiplayer

## 목표

플레이어는 군 입대 후 **18일 동안 다양한 군 생활을 버티며 생존**해야 한다.

매일 주어지는

- 일과
- 보직 퀘스트
- 협동 퀘스트
- 훈련

을 모두 완료해야 하루를 생존할 수 있다.

하루라도 실패하면 Game Over.

# 26. 차별화 요소

## Dynamic Military Simulation

모든 시스템이 서로 영향을 준다.

```
계절

↓

온도

↓

날씨

↓

훈련 종류 변경

↓

플레이어 컨디션 변화

↓

보직 퀘스트 변경

↓

협동 퀘스트 발생

↓

팀 평가 변경

↓

최종 엔딩 변경
```

플레이할 때마다

- 날씨
- 훈련
- 이벤트
- 퀘스트

가 모두 달라지므로 매 판 새로운 플레이 경험을 제공한다.
