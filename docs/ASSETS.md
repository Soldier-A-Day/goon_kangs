## 0. 예산 근거

기획서 18.0 ARCH-03에서 확정된 제약이 모든 수치의 출발점이다.

| 제약 | 값 | 출처 |
|---|---|---|
| 플랫폼 | 데스크톱 웹 (Unity WebGL2), 모바일 제외 | ARCH-03 |
| 동시 플레이어 | 4인 (보직 1:1) | 3.0 |
| 초기 다운로드 | ≤ 120MB | 표 18-2 |
| 맵 번들 | ≤ 30MB / 개 | 16.0 |
| 메모리 힙 | ≤ 1GB | 표 18-2 |
| 프레임 | 60fps / 최저 30 — **완화 불가** | 표 18-2 |
| 텍스처 압축 | DXT 단일 (ASTC 불필요) | ARCH-03 |

### 화면 예산 (동시 표시)

| 항목 | 목표 | 비고 |
|---|---|---|
| 삼각형 | **≤ 700K tris** | 야외 최대 부하 기준 (행군·유격) |
| 드로우콜 | **≤ 800** | WebGL2는 폴리보다 드로우콜이 병목. 정적 배칭 + GPU 인스턴싱 필수 |
| 실시간 그림자 광원 | 1개 (태양) | 나머지는 라이트맵 베이크 |
| 텍스처 메모리 | ≤ 350MB | 힙 1GB 중 |

이 문서의 폴리 수치는 모두 **LOD0 기준**이다. LOD1 = 50%, LOD2 = 20%, LOD3(임포스터) = 5% 를 기본 감산율로 한다.
