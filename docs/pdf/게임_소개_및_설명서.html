01게임 개요

네 명이 한 분대가 되어 18일 동안 병영 생활을 버티는 협동 게임이다. 매일 주어진 일과를 해내고 밤 점호를 통과해야 다음 날로 넘어간다.

이 게임의 난이도는 조작이 아니라 분업과 시간 배분에 있다. 하루는 여섯 시간대로 쪼개져 있고 각 시간대는 짧다. 부대는 걸어서 다녀야 할 만큼 넓으며, 훈련장은 아예 부대 밖에 있다. 그래서 "누가 어디로 가서 무엇을 할 것인가"를 매 시간대마다 다시 정해야 한다.

보직은 잘하면 좋은 특기가 아니라 그 사람이 못 하면 나머지 셋이 손해를 보는 자리다. 통신병이 무전 유지를 놓치면 전원의 미니맵에서 마커가 사라지고, 의무병이 밀리면 분대 전체의 수분 소모가 두 배가 된다. 개인의 실패가 개인에게만 돌아오지 않는 구조가 협동을 강제한다.

02하루의 흐름

하루는 여섯 시간대로 자동으로 흐른다. 시간이 다 되면 다음 칸으로 넘어가고, 못 끝낸 일과는 그대로 미완료로 남는다. 분대가 모두 준비됐다면 화면의 [투표하기]로 남은 시간을 건너뛸 수 있으며, 아낀 시간은 사라지지 않고 다음 시간대의 여유로 이월된다.

필수와 선택

시간대마다 할 일이 배정된다. 수첩(TAB)을 열면 필수와 선택이 나뉘어 보인다.

  • 필수 — 그날 밤 점호에서 세는 것. 하나라도 남으면 판정이 깨진다. 소유자를 가리지 않는다 — 분대원 것이 남아도 분대 전체가 걸린다.
  • 선택 — 안 해도 그날은 무사하다. 다만 승급에 쓰이는 복무 점수는 오직 선택 일과에서만 쌓인다. 필수만 겨우 채우며 버티면 계급이 오르지 않는다.
설계 의도 필수는 오늘을 살아남는 일, 선택은 18일 뒤를 준비하는 일이다. 필수 완수는 살아 있는 플레이어라면 예외 없이 100%라 변별력이 0이므로, 승급 기준으로 쓸 수 없다. 그래서 "안 해도 되는데 한 것"만 점수로 매긴다.

밤 점호 — 네 가지 조건

조건판정
A미완료 필수가 0인가 (구제권으로 상쇄 가능)
B합동 퀘스트가 통과했는가 (부분 성공 70%까지 인정)
C군기 게이지가 바닥을 넘는가
D전원의 청결·필수 장비 소지가 기준을 넘는가

A와 D는 특정 인원을 지목해 보여주고, B와 C는 분대 공통이라 지목이 없다. 판정 요약을 전원이 확인해야 다음 날이 시작되며, 그동안 시간은 멈춰 있다.

분대장과 구제권

런이 시작되면 넷 중 한 명이 분대장이 된다. 무작위가 아니다 — 소총수 → 통신병 → 의무병 → 행정병 순서에서 실제 사람이 맡은 첫 자리가 분대장이 된다 (리플레이·시뮬레이션 재현성 때문에 결정적으로 뽑는다). 머리 위 이름표 옆 다이아몬드가 그 표시다. 접속 중인 인원의 과반이 한 사람에게 표를 주면 즉시 교체되고, 2:2 동수면 현직이 유지된다.

구제권은 오늘 안에 못 끝낼 것 같은 필수 일과 하나를 선택으로 내려, 그날 점호에서 세지 않게 만드는 권한이다.

몫수량발동 조건
분대장 몫2분대장이 미완료 필수 하나를 지정한다. 분대원의 필수도 내릴 수 있다
간부 몫1저녁 개인정비 시간에, 신뢰도 최고 간부의 신뢰도가 문턱을 넘을 때
주의 구제권은 런 전체에서 총 3장이고 하루가 지나도 다시 차지 않는다. 되돌릴 수도 없다. 발동 시 확인 창이 한 번 뜬다.

계급과 승급 심사

3일차 · 9일차 · 15일차에 승급 심사가 있다. 통과하면 이병 → 일병 → 상병 → 병장으로 오른다. 기준은 복무 점수이며, 앞서 말한 대로 선택 일과에서만 쌓인다. 보류되어도 다음 정비일에 재심사를 받고 그때는 요구치가 10% 낮아진다 — 초반에 뒤처져도 만회할 여지를 남긴다.

04맵과 이동

부대는 244 × 224 타일의 단일 심리스 월드다. 구역 36개, 배치 소품 483개로 이루어진다. 텔레포트는 없다 — 모든 이동은 걷기다.

부대 안

생활관동·급양동·행정동 등 건물이 복도로 이어져 있고, 방 하나가 곧 하나의 구역이다. 문은 전부 열려 있으며, 지도에서 주황색 선이 문을 뜻한다.

부대 밖 — 훈련장 10곳

훈련장은 전부 외곽 철조망 바깥에 있다. 나가려면 정문 위병소를 통과해야 하고, 정문에서 각 훈련장까지 아스팔트 길이 깔려 있다. 길은 미니맵과 전체 지도에도 그려지며, 훈련장 입구는 주황색 표시와 바깥쪽 꼬리로 구별된다.

05일과와 미니게임

목표 앞에서 E를 누르면 일과가 시작되고, 대부분은 짧은 미니게임으로 이어진다. 미니게임은 14가지 원형이 있으며 날짜에 따라 점진적으로 해금된다.

하달 — 일과 넘기기

오전·오후 일과는 20초 하달 창으로 시작한다. 이 동안 시간대 타이머는 정지하므로 눈치싸움에 실제 일과 시간을 쓰지 않는다. 공통 일과만 넘길 수 있고 보직 전용은 넘겨도 수행이 불가능하다. 전원이 확정하면 창은 즉시 닫힌다.

타이핑 없이 협동한다

설계 원칙 하나가 "타이핑을 전혀 하지 않고도 18일 완주가 가능해야 한다"이다. 협동 퀘스트 대부분은 Q 퀵 커맨드 8종과 C 정형 문구 8종으로 해결된다. 초를 다투는 상황에서 채팅을 칠 시간이 없기 때문이다.

07실행 방법

A. 플레이 (설치 없음)

브라우저에서 아래 주소로 접속한다. 별도 설치나 플러그인이 필요 없다.

구분주소
웹 (로비 · 게임)https://solider-a-day.vercel.app
게임 서버https://sad-gameserver.onrender.com
  1. 로비에서 이름을 입력하고 보직을 고른다.
  2. [새 분대 만들기] — 초대 코드가 생성된다. 링크를 복사해 친구에게 보낸다.
  3. 초대받은 사람은 /join/코드 링크로 들어온다 — 코드 입력도 보직 선택도 필요 없다(자동 배정).
  4. 전원이 모이면 방장이 [시작]을 누른다.
첫 접속이 느릴 수 있다 게임 서버가 무료 플랜이라 15분간 요청이 없으면 잠든다. 로비에 들어오는 순간 자동으로 깨우는 신호를 보내므로, 편성을 마칠 때쯤이면 이미 깨어 있다. 그래도 첫 응답이 느리면 잠시 기다리면 된다.

B. 로컬 개발 환경

Node.js 20+ 와 npm이 필요하다. Unity(6000.0.80f1)는 게임 클라이언트를 다시 빌드할 때만 필요하며, 이미 빌드된 번들이 저장소에 있으므로 웹·서버 개발에는 없어도 된다.

명령하는 일
npm install워크스페이스 전체 의존성 설치
npm run dev웹 셸 (Next.js) — 기본 :3000
npm run dev:server게임 서버 (HTTP + WebSocket) — 기본 :8080
npm run test전 워크스페이스 테스트 (531건)
npm run typecheck전 워크스페이스 tsc --noEmit
npm run sim -- …헤드리스 밸런싱 시뮬레이터 (Unity 없이 18일 실행)
python3 tools/sprites/generate.py2D 에셋 전량 재생성 (488장)
node tools/webgl-sync.mjsUnity 빌드 산출물을 웹 public/game으로 동기화

환경변수를 하나도 주지 않아도 실행된다 — 저장소는 인메모리로, 서버 주소는 localhost로 폴백한다. 운영 배포 시에만 Upstash Redis · Supabase · CORS 설정이 필요하다.
